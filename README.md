# ПРОЕКТ 1. Анализ поведения пользователей и ключевых продуктовых метрик маркетплейса

**Цель**
Анализ текущих показателей маркетплейса, выбор приоритетной гипотезы и формирование рекомендаций по улучшению продаж.

**Стек**
Python, Pandas, NumPy, Seaborn, Matplotlib, Jupyter Notebook.

# Реализация проекта
- Проанализировала данные о покупателях и заказах маркетплейса из CSV-файлов объемом
около 40 МБ.
- Провела когортный анализ и оценила месячный retention в повторный заказ. Рассчитала и
проанализировала ключевые продуктовые метрики: GMV, Monthly Active Buyers, retention и
ARPPU. Создала дерево метрик эксперимента.
- Визуализировала динамику метрик и результаты когортного анализа с помощью Seaborn.
- Выявила ключевую проблему продукта: пользователи преимущественно совершали разовую
покупку и не возвращались, что ограничивало рост выручки.

# Результат
Анализ показал, что основная зона роста находится не в масштабировании
привлечения, а в удержании и пользовательском опыте. Для дальнейшей проверки была
сформирована приоритетная продуктовая гипотеза и система метрик. Получила
максимальный балл за проект.
